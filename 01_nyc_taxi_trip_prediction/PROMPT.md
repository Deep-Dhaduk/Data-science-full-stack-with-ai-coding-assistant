# Prompt

> Build an end-to-end data-science project using the Kaggle NYC taxi challenge, including data, training, deployment, CRISP-DM, an interactive map, and trip estimation. Add a detailed data-science dashboard and research-oriented model iteration.

## Interpretation

The first reproducible slice focuses on a correct holdout workflow, geospatial and cyclical features, two regression targets, visible evaluation, and an inference UI. It runs offline on explicitly synthetic data; a licensed Kaggle/TLC ingestion adapter and map tiles are planned enhancements.
