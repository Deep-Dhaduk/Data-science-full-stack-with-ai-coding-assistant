# Prompt

> Design an end-to-end SPY time-series forecasting system using state-of-the-art machine learning. Prevent feature leakage, include an independent data-science auditor, prepare detailed specifications and UML, and render diagrams correctly.

## Interpretation

The reproducible core prioritizes validity over model-name spectacle: strictly lagged features, a chronological split, purge gap, train-only robust scaling, naive baseline, transaction costs, drawdown, stress controls, and an unmistakable synthetic-data disclaimer.
