# Prompt

> Build a large, transparent NYC taxi CRISP-DM platform with EDA, explainability, clustering, research across techniques and hyperparameters, inference APIs, MLOps, code auditing, verification, and a detailed report.

## Interpretation

This independently implemented capstone integrates a three-model tournament, holdout metrics, permutation explanations, mobility clustering, a PSI drift scenario, explicit audit controls, a model card, and typed inference.
