# Prompt

> Build a simple LLM and chatbot using modern primitives while fitting on a laptop GPU. Follow CRISP-DM, include an admin dashboard, research the architecture, iterate experimentally, diagnose corrupt output, and train on better sample data.

## Interpretation

This is an honest educational language model rather than a wrapper around a hosted API. The app exposes its parameter count, fixed corpus, optimizer loss, architecture, and limitations. Training is user-triggered so startup stays fast.
