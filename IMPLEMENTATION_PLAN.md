# Implementation plan

## Definition of done

A project is complete only when its model logic runs without network access on deterministic demonstration data, its API and dashboard start, its tests pass, and its README states provenance and limitations. External datasets are optional enhancements and may never be silently substituted for generated data.

## Scientific safeguards

1. Split before fitting preprocessing.
2. Use chronological splits for time series.
3. Select metrics that match the business and class balance.
4. Compare against a naive baseline.
5. Pin randomness and report data provenance.
6. Label simulated outputs and never invent benchmark results.
